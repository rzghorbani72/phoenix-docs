System at a glance

In one sentence: Soniox (cloud) transcribes the employee → a Gemma-4 26B-A4B model decides the turn is over → aiva runs guardrail, retrieval (Hakim embeddings + Gemma-4 E2B filter) and a Gemma-4 31B ReAct agent (guardrail and agent share one dedicated 31B instance) → neurobox TTS speaks the answer → after hang-up, grogu re-transcribes the call and the external CCA engine tags it for the EX panel.
Things to know before you read: prod runs code that is not on local main. Two steps send employee data outside the cluster (Soniox speech-to-text, OpenAI greeting). The LLM call-tagging engine (CCA) and the EX panel source are not in our repos. See Risks & gaps.
