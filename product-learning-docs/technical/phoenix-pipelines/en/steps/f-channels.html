Channels and streaming (first and last chunk)

Live

Tokens move from the model to the caller through channels: small async pipes, like Go channels. The LLM stream writes into one, the agent forwards into its own, and the orchestrator forwards into the request's output channel. Closing a channel is how 'the answer is finished' is signalled.

Class
Chan (agentlib/utils/aio/channels.py:16)
Capacity
unbounded by default (maxsize=0)
End of stream
close(); iteration then stops (:108-152)
What flows
ChatChunk with a delta: text token, reasoning token, function call, function output, usage

The chain of channels for one answer

  1. OpenAILLMStream reads the provider's server-sent events and writes parsed chunks into its channel (agentlib/llm/openai/stream.py:20-29).
  2. The stream is teed: one copy goes to the agent, one to a metrics monitor that measures time to first token and token usage (agentlib/core/abc/chat/llm_stream.py:38-47).
  3. The agent forwards every chunk to agent.chan (agentlib/core/agents/stream/agent.py:146-148) and closes it when done (:237).
  4. The orchestrator forwards to orchestrator.chan and publishes FirstChunkEvent / LastChunkEvent (F3).
  5. ADCS turns orchestrator.chan into the SSE response that the voice agent reads (lane 1, V7).

What a TPM should know

  • Reasoning tokens and tool-call chunks travel on the same channel as spoken text. Whoever consumes the stream must filter them; aiva / the voice agent do this (inferred from the chunk types).
  • An agent's channel can only be used for one answer: once closed it stays closed. That is why aiva builds a new orchestrator and agents on every request (aiva/chat/handlers/chat.py:92-223).

Gotchas

In 0.45.0, sending to a closed channel raises ChanClosedError. The agent checks before forwarding a model chunk, but not before forwarding a tool result (stream/agent.py:150-157), so a cancelled branch that was mid tool call can raise (inferred).

What changed on main

0.46.1 skips tool execution entirely when the channel is already closed, and send_nowait gained raise_on_closed / raise_on_full switches.
