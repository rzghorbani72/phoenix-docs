What agentlib is, and which version prod runs

Live

agentlib is a small in-house framework (about 6,000 lines of Python) for building chat agents out of independent pieces that talk through events. It gives aiva its event bus, its ReAct answer agent, its guardrail agent, its OpenAI-compatible LLM and embedding clients, and its Qdrant retrieval. aiva pins an older release (0.45.0) on purpose.

What and why, in plain words

Instead of one long function that does every step of a chat turn, agentlib splits the turn into small handlers that each wait for some events and publish new ones. One handler embeds the text, three others search Qdrant in parallel, another runs the LLM. The orchestrator is the glue that turns one event into the next. This makes it easy to add a parallel step (aiva adds intent detection, clarifying and classification this way) without rewriting the others. The cost is that the flow is hard to read from the code: you must follow the events.

How to read the code refs in this lane

Paths like agentlib/core/event/bus.py:130 are inside python/agentlib at commit 7c7bb1de6 (the 0.45.0 release). Do not read the agentlib folder at the aiva prod commit 206e55746: there it is already 0.47.4, which is not what prod installs. Earlier research notes that cited agentlib at 206e55746 therefore describe 0.47.4 code; for the parts this lane checked, the behaviour is the same except where a step says otherwise.

Watch out

aiva main (7b7c602eb) still pins 0.45.0. The bug fixes in 0.46.x (cancelled tasks, span concurrency, channel-closed errors) do not reach EX until someone upgrades and re-validates Phoenix tracing.
The library has almost no written docs: the Sphinx site is two diagrams plus auto-generated API pages, and the diagrams use some old names (see F3).
